# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-11

### Added
- Clipboard history panel in the menu bar, with search.
- Global shortcut ⌘⇧V to open it from anywhere.
- Pick to paste into the previous app (Accessibility), ↑/↓ + Return and ⌘1–⌘9 quick paste.
- Keeps original formatting (RTF/HTML); hold ⌥ to paste plain text.
- Image history with thumbnails.
- Favorites that are never trimmed.
- Preview pane with full text or image.
- Skips concealed/transient data from password managers.
- Launch at Login, About window.
- English and Spanish localizations.
